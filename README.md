# Комп'ютерний практикум №1. Багаторозрядна арифметика

Реалізація бібліотеки для роботи з беззнаковими багаторозрядними цілими числами фіксованої довжини (до 2048 біт) мовою C++.

## Архітектура представлення чисел

Число зберігається як масив із 64 слів розмірністю 32 біти кожне (`uint32_t digits[64]`), що становить 2048 біт у форматі little-endian.

Усі базові арифметичні операції виконуються в кільці залишків за модулем $2^{2048}$. У разі виходу результату за межі старші біти відсікаються, а факт переповнення або позики фіксується внутрішніми змінними `carry` та `borrow`.

Для алгоритмів стовпчикового множення (`mul`) та піднесення до квадрата (`square`) реалізовано підтримку розширеного буфера розміром 128 слів (`uint32_t[128]`, 4096 біт), що дозволяє обчислювати повний добуток без втрати старших розрядів.
