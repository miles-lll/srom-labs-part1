# Комп'ютерний практикум №1. Багаторозрядна арифметика

Реалізація бібліотеки для роботи з беззнаковими багаторозрядними цілими числами фіксованої довжини (до 2048 біт) мовою C++.

## Архітектура представлення чисел

Число зберігається як масив із 64 слів розмірністю 32 біти кожне (`uint32_t digits[64]`), що становить 2048 біт у форматі little-endian.
